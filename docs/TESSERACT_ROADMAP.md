# مسیر آزمایشی Tesseract و وضعیت پذیرش

تاریخ: ۲۰۲۶-۱۰-۲۱. وضعیت: پیاده‌سازی آزمایشی، **معیار کیفیت تأمین نشده است؛ فعال‌سازی مجاز نیست**.
پیش‌فرض `OCR_PIPELINE_MODE=legacy` باقی می‌ماند. دادهٔ مشتری و مرجع رونویسی در Git قرار ندارند.

## مسیر واقعی پروژه

این مخزن سامانهٔ مستقل Flask روی `ocr.gomrok.org` است؛ مخزن FastAPI با نام
`LLM-FINAL` و گزارش‌های OCR-01/OCR-02 پروژهٔ دیگری هستند. آن برنامه یا دیتابیس آن
برای این کار اجرا نشده است. در این مخزن مصرف‌کنندهٔ نمایهٔ جست‌وجو وجود ندارد.

مرورگر از API داخلی بارگذاری، وضعیت، پیش‌نمایش و دانلود استفاده می‌کند. تشخیص متن
روی همان سرور با Tesseract انجام می‌شود. پیاده‌سازی شبکه‌ای Google Vision حذف شده؛
نام کلاس قدیمی صرفاً نماد سازگاری غیرفعال است. آرگومان قدیمی `api_key` در صورت
دریافت کلید، خطای روشن می‌دهد و هیچ کلیدی خوانده یا ارسال نمی‌شود. مسیر جدید
فقط executable محلیِ پین‌شده را اجرا می‌کند؛ دانلود مدل، Docker fallback، LLM، VLM
و موتور OCR دیگری ندارد. دانلود عمومی بستهٔ Pillow فقط برای نصب محیط آزمایش انجام شد.

مسیر فعلی: `web_app.upload → process_pdf → render_master → ocr_page → TXT/JSON/tables`.
مبنای ثبت‌شده revision `ccbee48b7ec4a2e3d066a51422a1ee23eb29fbf8`، زبان `fas`، رندر
۲۰۰۰ DPI و موتور محلی با workerهای موجود است. فایل‌های زبان همین مبنا نیز از نظر
بایت با `tessdata_best` منطبق‌اند؛ آزمون جدیدی با ادعای «best بهتر از fast» انجام نشده است.

## حالت‌ها و اجرای محدود

| حالت | خروجی فعال | رفتار |
| --- | --- | --- |
| `legacy` | قالب‌ها و الگوریتم قبلی | پیش‌فرض؛ بدون اتصال OCR بیرونی |
| `compare` | خروجی قبلی | نتیجهٔ نامزد در snapshot جدا؛ شکست نامزد در `comparison.json` آشکار است |
| `candidate` | پیش‌نویس مسیر جدید | هنوز برای استفادهٔ عملیاتی و پذیرش خودکار تأیید نشده است |

برای محیط آزمایش مستقل، پیش از import برنامه `OCR_DATA_DIR`، `OCR_TEMP_DIR`،
`TEMP` و `TMP` را روی فضای خصوصی کافی تنظیم کنید. هیچ‌کدام را روی فضای مشتری،
مسیر Git یا ریشهٔ IIS قرار ندهید. حداقل ۱٫۵ GiB ذخیرهٔ ایمنی حفظ می‌شود.
نبود `OCR_DATA_DIR` مطلق پیش از import وب، خطای روشن می‌دهد؛ fallback به مسیر
پیش‌فرض وجود ندارد. `serve.py` عملیاتی این مقدار را پیش از import تنظیم می‌کند.

```powershell
python scripts/run_isolated_tests.py --root E:/ocr-private-test-run
python -m pip install -r requirements-candidate.txt
python ocr_bot.py sample.pdf --mode compare --out E:/ocr-trials --temp-dir E:/ocr-private-temp
python ocr_bot.py sample.tiff --mode candidate --profile mixed --candidate-dpi 300 --out E:/ocr-trials --temp-dir E:/ocr-private-temp
python ocr_bot.py handwritten.pdf --mode candidate --handwriting --out E:/ocr-trials --temp-dir E:/ocr-private-temp
```

نصب بسته‌ها فقط در محیط آزمایشی مستقل انجام شود؛ دستور نصب بالا قرار نیست روی
runtime فعال اجرا شود. `requirements-candidate.txt` نسخه‌های مشاهده‌شده و Pillow
را ثابت می‌کند. وابستگی‌های مسیر فعال در این مرحله ارتقا داده نشده‌اند.

پروفایل‌های `persian=fas`، `mixed=fas+eng` و `english=eng` با OEM 1 تعریف شده‌اند.
موتور فعلی دقیقاً `tesseract v5.5.3.20260724` و SHA-256 آن در `precision/profiles.py`
پین شده است. فایل‌های زبان، مبدأ رسمی، commit و تطبیق Git blob در
[SOURCES.md](../tessdata/SOURCES.md) ثبت شده‌اند. جایگزینی executable یا فایل زبان
به خطا منجر می‌شود؛ روی سیستم دیگر باید نصب مشخص و ارزیابی جدید ثبت شود.

`Options` در `precision/profiles.py` تنظیمات قابل خاموش‌کردن کجی، کنتراست،
آستانه‌گذاری، نویزگیری ملایم، سایه و حاشیهٔ سیاه را دارد. نویزگیری، سایه و حذف
حاشیه به‌طور پیش‌فرض خاموش‌اند. چرخش و چهار گوشهٔ پرسپکتیو فقط با ورودی صریح
اپراتور اعمال می‌شوند. OSD و تشخیص خودکار معتبر گوشه/دست‌نویس در این نسخه وجود ندارند.
تشخیص زاویه از خطوط هندسی نامطمئن، تصویر اصلی را نمی‌چرخاند.

PDF همیشه به تصویر تبدیل می‌شود؛ متن داخلی PDF موجب رد OCR نمی‌شود. تصاویر
PNG/JPEG/BMP و TIFF چندصفحه‌ای در حالت نامزد پشتیبانی می‌شوند. در وب، ورودی
تصویر و انتخاب پروفایل فقط در همین حالت فعال‌اند. کنترل شش‌مرحله‌ای قدیمی حفظ شده؛
مسیر نامزد وضوح مستقل ۳۰۰ یا ۴۰۰ دارد. تصویر مرجع هر صفحه پیش از اصلاحات ذخیره
می‌شود؛ ماتریس مستقیم و معکوس هر نامزد، کلمات را به پیکسل همین مرجع برمی‌گرداند.

PSM 3 برای صفحه، 6 برای بلوک/سلول و 7 برای خط استفاده می‌شود. سقف هر ناحیه شش
خوانش است و مشاهدهٔ پایه و خوانش ناموفق را هم شامل می‌شود. پیش‌فرض هر صفحه ۳۲
ناحیه و ۸۰ اجرای اضافی است. در آزمون واقعی این مرحله، سقف‌ها ۱۶ و ۴۰ بوده‌اند.
نواحی بررسی‌نشده ثبت می‌شوند. تشخیص پوشش در قطعات هم‌پوشان با پیکسل‌های کامل انجام
می‌شود؛ کوچک‌سازی فقط برای هزینهٔ تحلیل زاویه است. تشخیص جدول هندسی یک نامزد است؛
مرزهای ناقص/سلول ادغام‌شده باعث گزارش ابهام می‌شوند، نه ساخت جدول فرضی.

هر صفحه سقف ۲۵ میلیون پیکسل، هر ورودی ۵۱۲ MiB، هر سند ۳۰۰ صفحه و هر تلاش ۹۰ ثانیه
دارد. بودجهٔ artifact پیش‌فرض یک GiB در مرز صفحات بررسی می‌شود؛ حداکثر رشد یک صفحه
می‌تواند قبل از توقف اضافه شود. سقف snapshot برابر ۶۴ MiB، شواهد بازخوانی هر صفحه
۱۶ MiB و زمان سند یک ساعت است. زمان در مرز صفحه و پیش از بازخوانی بررسی می‌شود؛
تلاش در حال اجرا حداکثر تا timeout خودش ادامه دارد. TSV هر تلاش حداکثر ۴ MiB و
۱۰۰۰۰ کلمه است. رسیدن به سقف‌ها با دلیل آشکار گزارش می‌شود. شکست صفحه، صفحات دیگر
را حذف نمی‌کند. تنها تصویر
کاملاً سفید شاهد سفیدبودن است؛ خروجی خالی روی صفحهٔ کم‌رنگ نیازمند بازبینی می‌ماند.
گسترش شبکهٔ جدول در هر صفحه حداکثر ۲۰۰۰ سلول دارد؛ شبکهٔ بزرگ‌تر با ساختار نامعلوم
گزارش می‌شود و کلمات آن در مسیر سطرها باقی می‌مانند.

## قرارداد، بازبینی و تحویل به جست‌وجو

مسیر `extractions/<revision>/` شامل JSON/TXT، تصاویر مرجع، TXT/TSV خام تلاش‌ها و
جدول‌های همان snapshot است. revision از هش منبع، تنظیمات، محدودیت صفحه و هش کد
محاسبه می‌شود. بازاجرای همان snapshot دوباره OCR اجرا نمی‌کند. اصل سند و snapshot
قبلی بازنویسی نمی‌شوند. نامزد و مسیر قدیمی قرارداد `document/pages/performance`
را حفظ می‌کنند و metadata افزایشی دارند. CSV/HTML جدول حفظ شده‌اند؛ XLSX فقط در
صورت وجود writer قبلی تولید می‌شود و نبود آن در metadata آشکار است.

`engine_text_raw` صفحه مشاهدهٔ مستقیم موتور است؛ متن ناحیه ممکن است projection
کلمات TSV باشد و نوع آن صریح ثبت شده است. متن کامل برش در `context_text_raw`
و فایل خام باقی می‌ماند. `content_text`، `normalized_text` و `search_text` جدا هستند.
تفاوت عددی با نامزد دیگر موجب جایگزینی خودکار مقدار پایه نمی‌شود. ارقام، واحدها،
صفر ابتدایی و جداکننده‌ها در رشته باقی می‌مانند. هیچ اصلاح املایی یا تکمیل زبانی نیست.

`/reviews` محیط بازبینی نشست است: صفحهٔ کامل، کادر ناحیه، خوانش‌های واقعی، دلایل
ابهام، اصلاح، تأیید یا ناخوانا. `/reviews/<id>` با POST فقط نسخهٔ مورد انتظار را
می‌پذیرد؛ تعارض 409 است. CSRF، مالکیت نشست، اندازهٔ ۱۲۸ KiB درخواست، حداکثر
۱۰۰ اصلاح و ۱۰۰۰۰ نویسه برای هر واحد کنترل می‌شوند. ذخیرهٔ state اتمیک، همراه با
قفل thread و قفل فایل بین processهاست. تاریخچه و متن خام جدا می‌مانند.
نسخهٔ بازبینی پس از restart و با همان کلید نشست و cookie معتبر قابل بازیابی است؛
این سامانه حساب کاربری دائمی یا بازیابی نشست منقضی‌شده ایجاد نمی‌کند.

`/reviews/<id>/search` یک مجموعهٔ `replace_document` با شناسهٔ ثابت، نسخه،
متن تأییدشده، صفحه و bbox می‌دهد. متن نرمال فقط از اصلاح تأییدشده ساخته می‌شود.
لغو تأیید، متن آن واحد را از مجموعه حذف می‌کند. مصرف‌کننده باید نسخه را کنترل و
کل مجموعهٔ همان سند را جایگزین کند تا متن قدیمی/تکراری نماند. **مصرف‌کننده‌ای در
این مخزن متصل نیست؛ انتشار در دانشنامه یا نمایه انجام نشده است.**

فعال‌کردن revision جدید بازبینی، اقدامی جداست؛ ثبت پردازش جدید به‌تنهایی نسخهٔ
تأییدشده را عوض نمی‌کند. برای بازگشت، هم حالت pipeline را به `legacy` برگردانید،
هم revision قبلیِ بازبینی را فعال کنید و مجموعهٔ `replace_document` همان نسخه
را به مصرف‌کنندهٔ موجود بدهید. تاریخچه و تأییدهای هر دو نسخه حفظ می‌شوند.

## نتیجهٔ ارزیابی فعلی

مرجع پیشین برای هر پنج صفحه همچنان `human_verified=false` است. پاسخ کوتاه
«تأیید» فاقد بازبین، نسخه و زمان تطبیق تصویر بود و به تأیید انسانی تبدیل نشد.
دو سند در مجموعهٔ تنظیم‌اند؛ سند مستقل آزمون صفر، نمونهٔ دست‌نویس معتبر صفر است.
۲۶ ناحیه با مجموع ۷۳۶۴ نویسه/۱۳۸۹ واژه، بدون حذف نمونهٔ سخت یا فیلتر confidence
مقایسه شدند. نتایج زیر **تشخیصی و موقت** هستند، نه دقت کل صفحات یا کل آرشیو.

| معیار micro در همان محدوده | مبنا | نامزد |
| --- | --- | --- |
| CER محتوایی | ۲۱٫۰۲۱۲٪ | ۲۶٫۴۱۲۳٪ |
| S / D / I نویسه | ۱۰۵۷ / ۳۴۵ / ۱۴۶ | ۱۱۲۱ / ۷۰۶ / ۱۱۸ |
| WER محتوایی | ۳۷٫۸۶۹۰٪ | ۴۲٫۰۴۴۶٪ |
| CER مشاهدهٔ موتور در محدودهٔ TSV | قابل محاسبهٔ معتبر نیست | ۲۶٫۴۹۳۸٪ |

ترتیب آرایهٔ کلماتِ مبنا، ترتیب متن تحویلی نبود؛ ارزیابی اولیه‌ای که آن‌ها را یکی
گرفته بود کنار گذاشته شد. جدول بالا از ترتیب واقعی تولیدکنندهٔ قدیمی استفاده می‌کند؛
کاهش ظاهریِ معیار اولیه نتیجهٔ معتبر نیست. CER/WER جدید S/D/I/N دارند، micro جمعی‌اند،
مرجع خالی مقدار نامعین دارد و CER بیش از صد درصد محدود نمی‌شود. اثر نشانگرها با
metadata قطعات افزوده و alignment جدا سنجیده می‌شود؛ regex حذف نشانگر وجود ندارد.

۲۲۰ ناحیهٔ نامزد پیش از بازبینی تأیید نشده‌اند، اصلاح انسانی روی اسناد واقعی صفر است؛
پوشش پذیرش خودکار برای جست‌وجو صفر است. این عددِ محافظه‌کارانه بهبود OCR نیست.
۳۵۲۸ نویسهٔ افزودهٔ سیستم در TXT پنج صفحه ثبت شده است. CER کامل Export، پوشش خط،
ترتیب مستقل و صحت سلول/عدد به دلیل نبود مرجع کافی **اندازه‌گیری نشده‌اند**.
گروه «سند دارای جدول» در گزارش، کیفیت سلول‌های جدول محسوب نمی‌شود.

در یک ناحیهٔ مرتبط با سرنخ قبلی ۴↔۶، یک خوانش اضافی ۴۰۰ DPI با PSM 7 و تصویر
داخلی Tesseract ثبت شد. مقایسه‌های زبان قبلی روی همان crop دوباره تکرار نشدند.
نمونهٔ دقیق متصل به خروجی اصلی کاربر و مرجع مستقل عدد هنوز ناقص‌اند؛ رفع اصلی
۴↔۶، کلمهٔ ناقص یا سه‌نقطهٔ گزارش‌شده تأیید نمی‌شود.

**پذیرش رد شد:** خطای نامزد در این مقایسه بیشتر است و معیارهای عدد/مرجع مستقل هم
تأمین نشده‌اند. مسیر نامزد روی سایت فعال یا به‌عنوان ارتقای کیفیت منتشر نمی‌شود.

## بازتولید و محدودیت اعتبارسنجی

```powershell
python scripts/evaluate_extractions.py --reference E:/private/reference.json --predictions E:/private/predictions.json --output E:/private/new-report.json
```

schema در ابتدای script و `evaluation.validate_reference` مستند است. خروجیِ
گم‌شده hypothesis خالی است، نه نمونهٔ حذف‌شده. اسناد در سطح source hash بین تنظیم
و آزمون جدا می‌شوند. اعداد واقعی باید با field ID، صفحه و bbox و رشتهٔ کامل مرجع
ثبت شوند؛ synthetic فقط مسیر رشته/Unicode/Export را می‌آزماید.

آزمون‌های امنیت و عملکرد، ذخیرهٔ هم‌زمان بین processها، راه‌اندازی ایزوله و ممنوعیت
نوشتن خارج از root در process فرزند را پوشش می‌دهند. SQLite در آزمایش OCR ممنوع
است. این محدودیت مربوط به نوشتن کنترل‌شدهٔ برنامه است؛ ادعای «هیچ نوشتنی در کل C»
یا تغییرنکردن تاریخی محتوای دیتابیس مطرح نیست. وضعیت تاریخی همچنان UNKNOWN است.

آزمون HTTP واقعی با سند تولیدشده، دریافت TXT/JSON، پیش‌نمایش، بازبینی، مجموعهٔ
جست‌وجوی تأییدشده و جلوگیری از دسترسی نشست دیگر انجام شده است. قطع شبکه در سطح
سیستم‌عامل انجام نشده؛ مسیر OCR فاقد ارتباط بیرونی است و آزمون ممنوعیت socket در
کد Python اجرا شده است. نتیجهٔ آن به‌عنوان آزمون firewall سیستم‌عامل معرفی نمی‌شود.
مجموعهٔ نهایی ۱۴۸ آزمون در محیط ایزوله عبور کرد. syntax هر دو فایل JavaScript و
بازبینی امنیت مرزهای مالکیت، فایل، CSRF، ذخیرهٔ هم‌زمان و منابع نیز انجام شد.
این مخزن build فرانت‌اند یا ابزار typecheck/lint پیکربندی‌شده ندارد؛ بررسی syntax
و whitespace جای آن ابزارها یا بازبینی بصری معرفی نمی‌شود.

بازبینی بصری مرورگر **BLOCKED** است: ابزار داخلی خطای مسیر داد و اجرای مرورگر
محلی توسط بررسی خودکار مجوز با `blocked by policy` رد شد. syntax جاوااسکریپت و
قراردادهای HTTP بررسی شده‌اند، اما این‌ها جای مشاهدهٔ واقعی دسکتاپ/موبایل را نمی‌گیرند.
DOCX و PDF قابل جست‌وجو در این مرحله اضافه نشده‌اند؛ قالب‌های موجود حذف نشده‌اند.

شواهد خصوصی، snapshot کد اجراشده، خروجی‌های قبل/بعد و گزارش نهایی در
`E:/OCR-Tesseract-20261021` محفوظ‌اند. اجراهای ناموفق اولیه و ارزیابی ردشده حفظ و
از نتیجهٔ نهایی مستثنا شده‌اند. فایل اصلی PDF و گزارش‌های OCR-01/OCR-02 تغییر نکرده‌اند.
